GPT로 만든 앱을
인터넷에 올리기 🚀

아이패드 · 사파리만으로 · 설치 없이 · 15분

GPT가 만들어준 코드는 지금 내 화면 안에만 있다. 친구한테 보여주려면 캡처를 보내야 하고, 눌러볼 수도 없다.

인터넷에 올리면 주소 하나로 누구나 열 수 있다. 그 주소를 NFC 태그에 넣을 수도 있다.

왜 GitHub Pages인가? 아이패드에는 프로그램을 설치할 수 없다. GitHub Pages는 사파리만으로 전부 된다. 무료고, 고치는 것도 웹에서 한다.

1GPT에게 말하는 법 ← 제일 중요

배포하다 막히면 GPT에게 물어볼 것이다. 그런데 그냥 물으면 십중팔구 틀린 답이 온다.

GPT는 내가 어떤 기기를 쓰는지 모른다. 그래서 컴퓨터를 쓴다고 짐작하고 터미널에 명령어를 치라고 알려준다. 아이패드에는 터미널이 없다.

먼저 이걸 복사해서 붙여넣자

GPT에게 보낼 첫 문장

나는 아이패드를 쓰고 있어. 컴퓨터도 터미널도 없어. 사파리 브라우저만 써서 GitHub Pages로 HTML 파일 하나를 인터넷에 올리려고 해. 설치가 필요하거나 명령어를 치는 방법은 알려주지 마. 웹 화면에서 누르는 것만으로 되는 방법을 한 단계씩 알려줘.

이런 답이 오면 잘못된 길이다

> npm install -g firebase-tools
> git clone https://...
> cd C:\Users\...
> firebase deploy

터미널, 명령 프롬프트, 설치, npm, cd 같은 말이 나오면 아이패드에서 안 되는 방법이다. 이렇게 다시 말하자.

GPT가 터미널 방법을 알려줄 때

나는 아이패드라서 터미널이 없어. 그 방법은 못 써. 사파리에서 화면을 누르는 것만으로 되는 방법으로 다시 알려줘.

GPT는 아주 빠른 조수다. 하지만 내 상황은 내가 알려줘야 한다.
"안 돼요"라고만 하면 GPT도 뭘 도와야 할지 모른다.

2GitHub 계정 만들기

  1. 사파리에서 github.com/signup 접속
  2. 이메일 → 비밀번호 → 아이디(영어·숫자) 순서로 입력
  3. 이메일로 온 인증 코드 8자리를 입력하면 끝
아이디를 잘 정하자. 이게 그대로 내 사이트 주소가 된다.
https://내아이디.github.io/... ← 나중에 바꾸기 번거롭다.

3내 앱이 들어갈 방 만들기

GitHub에서는 프로젝트 하나를 저장소(Repository)라고 한다.

  1. 오른쪽 위 + → New repository
  2. Repository name: 영어로 짧게 (예: my-app, reading-app)
  3. Public을 고른다 ← 아주 중요
  4. Create repository
반드시 Public이어야 한다. Private으로 만들면 무료 계정에서는 주소가 아예 안 만들어진다. 여기서 제일 많이 막힌다.
Public이라고 겁먹을 것 없다. 우리가 올리는 건 어차피 누구나 볼 수 있는 웹페이지다. 비밀번호 같은 걸 코드에 적지만 않으면 된다.

4GPT 코드 붙여넣기

아이패드에 파일을 만들 필요가 없다. GitHub 웹에서 바로 만든다.

  1. GPT 화면에서 코드 블록 오른쪽 위 복사 버튼을 누른다
    캔버스(Canvas)에 있으면 캔버스의 복사 버튼
  2. GitHub 저장소 화면에서 Add file → Create new file
  3. 파일 이름 칸에 index.html 을 정확히 친다
  4. 아래 넓은 칸을 길게 눌러 붙여넣기
  5. 맨 아래(또는 오른쪽 위) Commit changes → 다시 한 번 Commit changes
파일 이름은 반드시 index.html
Index.html(대문자), index.htm, app.html 전부 안 된다. GPT가 다른 이름으로 알려줬어도 index.html로 바꿔서 만들자.
아이패드에서 화면이 좁으면 사파리 주소창 왼쪽 ᴀA → 데스크탑 웹사이트 요청을 누르면 편해진다.

5주소 만드는 스위치 켜기

파일만 올렸다고 주소가 생기진 않는다. 한 번 켜줘야 한다.

  1. 저장소 맨 위 Settings 탭
  2. 왼쪽 목록에서 Pages
  3. Branch를 main으로 바꾸고 Save
  4. 1~2분 기다린다 ← 바로 안 열려도 정상이다

새로고침하면 화면 위쪽에 초록색으로 주소가 나온다.

https://내아이디.github.io/저장소이름/

이 주소가 내 앱이다. 폰에서 열어보자 🎉

6고칠 때

GPT에게 수정을 부탁해서 새 코드를 통째로 받는 게 가장 쉽다.

  1. GitHub에서 index.html 을 누른다
  2. 오른쪽 위 연필 아이콘 ✏️
  3. 전체 선택 → 삭제 → 새 코드 붙여넣기
  4. Commit changes
  5. 1분쯤 뒤 주소를 새로고침
GPT에게 수정 부탁할 때

이 부분을 이렇게 고쳐줘. 고친 전체 코드를 처음부터 끝까지 한 번에 줘. 바뀐 부분만 주지 말고, 통째로 복사할 수 있게.

고쳤는데 그대로면? 아이패드가 예전 화면을 기억하고 있는 것이다.
탭을 완전히 닫았다 다시 열거나, 주소 뒤에 ?v=2를 붙여보자.

7막혔을 때 GPT에게 물어보는 법

에러가 나면 화면에 뜬 글자를 그대로 복사해서 붙여넣는다. 내 말로 바꿔 쓰면 GPT가 못 알아본다.

막혔을 때

나는 아이패드 사파리에서 GitHub Pages로 index.html을 올리는 중이야. 지금까지 이렇게 했어: (내가 한 순서를 적기) 그런데 이런 화면이 나왔어: (화면에 뜬 글자를 그대로 붙여넣기) 설치나 터미널 없이 해결하는 방법을 알려줘.

좋은 질문의 조건 세 가지
  • 내 기기가 뭔지 말한다 — 아이패드, 사파리
  • 내가 뭘 했는지 순서대로 말한다
  • 에러 글자를 그대로 붙여넣는다

8안 열릴 때

이런 일이이렇게 하면 된다
404 라고만 나온다 파일 이름이 index.html이 맞는지 / 1~2분 기다렸는지 확인
Settings에 Pages가 없다 저장소가 Private이다. Settings 맨 아래에서 Public으로 바꾸자
화면은 나오는데 글씨가 다 깨짐 코드 맨 위에 <meta charset="UTF-8">가 있는지 확인
이미지가 안 보인다 내 아이패드 안의 사진은 남에게 안 보인다. 이미지도 GitHub에 같이 올려야 한다
코드가 글자로만 보인다 파일 이름 끝이 .html이 아니다. .txt가 붙었는지 확인
붙여넣기가 안 된다 칸을 길게 눌러 붙여넣기 선택. 안 되면 데스크탑 웹사이트 요청

9마지막으로 — 올렸다고 끝이 아니다

GPT가 준 코드는 화면이 그럴듯해도 절반은 안 움직일 수 있다.

버튼에 '저장'이라고 써 있어도 진짜 저장되는지는 눌러봐야 안다. 글씨는 우리가 아무렇게나 쓸 수 있기 때문이다.

올린 다음 폰에서 직접 열어서 하나씩 눌러보자. 안 되는 걸 찾아내는 게 진짜 실력이다.

주소를 친구에게 보내보자. 내 아이패드에서만 되고 친구 폰에서 안 되면 아직 뭔가 빠진 것이다. 남의 기기에서 되는지가 진짜 확인이다.
